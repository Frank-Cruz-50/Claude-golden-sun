# Art test (M3 look check)

Custom, code-drawn art in a GBA JRPG style. **Nothing here is final until Frank approves the look.**

| File | What it shows |
|------|---------------|
| `field-ingame.png` | The real game running the `art_demo` map: open `http://localhost:5173/?map=art_demo` and press Start |
| `field-composite.png` | The same area rendered offline by the art scripts |
| `battle-mockup.png` | **Static mock-up** of a side-view battle (no battle code exists yet; that is M4) |

All art is generated by scripts in `tools/art/`, using Node built-ins only:

```
node tools/art/build.mjs          # regenerate assets/tilesets/field.png, assets/sprites/*.png, art_demo map
node tools/art/preview-map.mjs out.png
node tools/art/preview-battle.mjs out.png
```
