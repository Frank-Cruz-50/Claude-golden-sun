## Regenerating

All art is generated by scripts in `tools/art/`, using Node built-ins only:

```
node tools/art/build.mjs                         # tileset, sprites, UI, font, maps → /assets
node tools/art/preview-cast.mjs out.png          # character sheets close up
node tools/art/preview-full.mjs <map.tmj> out.png 2
node tools/art/preview-battle.mjs out.png
```

## How characters are drawn

Characters use the material-map renderer (`sprite.mjs`):

1. Each sprite is drawn as flat materials: hair, skin, cloth, leather, and so on.
2. The renderer adds 4-tone shading, coloured outlines, and shadow lines.
3. Hand-placed details go on top.

`people.mjs` shares the body, so a new character only defines a head (hair or hat), outfit, legs (`pants`, `shorts`, or `robe`), and weapon.
